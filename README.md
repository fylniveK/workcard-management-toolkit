# 智慧工卡管理平台

这是一个用 Python 和 Tkinter 编写的航空维修工卡员桌面辅助工具。它把当班信息、待办任务、常用文件和业务系统入口集中在一个界面中，减少重复查找与录入，并为部分固定步骤提供界面自动化。

## 功能概览

- **当班信息管理**：记录飞机号、定检级别、指令号、人员等信息，保存后供任务查询和表单生成使用；常用编号可一键复制。
- **待办清单与任务模板**：添加、完成、撤回和保存任务；按固定工作、周卡、换轮等场景批量生成待办，并提示工具借还事项。
- **文件与表单生成**：依据当班信息创建工作文件夹、航材需求单和定检交接单，自动填入可确定的基础字段。
- **系统与资料快捷入口**：集中打开常用业务页面、手册、件号资料、试车报告单和操作指南，减少在不同位置查找文件的步骤。
- **辅助界面自动化**：通过图像匹配、OCR 和键鼠操作，辅助登录、打开手册及执行部分查询。复杂业务处理和结果核对仍由使用者完成。

界面由快捷按钮区、当班信息区和待办事项区组成。更完整的操作流程与各按钮的使用条件见下方说明书。

## 公开版本说明

本项目公开前已进行脱敏处理。人员信息、账号、密码、执照号、内部地址和路径已替换为示例值；部分原始数据和文件已移除，`img` 目录中的真实图片也已替换为占位图。本项目仅作展示，依赖原内部工作电脑的环境与系统，无法在其他人的电脑上直接运行。

旧版维修平台模块此前已编写完成并可正常使用。公司系统更换后，相关自动化流程已注释停用。
